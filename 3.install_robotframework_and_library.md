# install robotframework and library

## install robotframework

```
## install python
python3默认已经安装
## install pip
sudo apt install python3-pip -y 
## check python and pip version
python3 -V
pip -V

## install robotframework
pip install robotframework

virtual environment安装到了venv/bin，venv/lib/python3.10/site-packages

不使用virtual environment，默认安装到了~/.local/bin
这个目录安装robotframework后还不在PATH里，所以这时robot命名找不到
退出bash重新打开或者重新加载环境变量source ~/.profile，安装目录就自动加到PATH里了
查看~/.profile
$HOME/.local/bin加到PATH里了

## check robot version
robot --version
```

## install robotframework-sshlibrary

```
pip install robotframework-sshlibrary

virtual environment，安装到了这里: venv/lib/python3.10/site-packages/
不使用虚拟环境，安装到了这里: ~/.local/lib/python3.10/site-packages/

Problem:
ERROR: Can not execute `setup.py` since setuptools is not available in the build environment.
Solution:
pip install setuptools
退出bash重新打开或者重新加载环境变量source ~/.bashrc
```
