# quick start

## mkdir, venv, pip install

```
mkdir rf_test
cd rf_test

python3 -m venv venv
source venv/bin/activate

pip install robotframework robotframework-sshlibrary robotframework-seleniumlibrary
```

## example 1

test.txt
```
***Settings***
Library    OperatingSystem

***Test Cases***
My First Test Case
    Log To Console    Hello, Robot Framework!
    Create File    example.txt    This is a test file.
    File Should Exist    example.txt
    Remove File    example.txt
```

Run test
```
robot test.txt
```

```
## chrome driver
查看安装的chrome版本，然后到下面的链接下载对应版本的chromedriver，放到venv/bin/下面
https://repo.huaweicloud.com/chromedriver/ 或者 https://googlechromelabs.github.io/chrome-for-testing/
```

```
*** Settings ***
Library    SeleniumLibrary

*** Variables ***
${url}        https://www.baidu.com/
${browser}    Chrome

*** Test Cases ***
access baidu
    Open Browser    url=${url}               browser=${browser}
    Input Text      id:chat-textarea         robotframework
    Click Button    id:chat-submit-button
    Sleep           5s
```
